# v0.1.0 — Market Opportunity Research

Initial release of a portable Agent Skill for investigating business ideas through buyer demand, real alternatives, commercial tradeoffs, and a first-customer experiment.

## Included

- Buyer-first research workflow with explicit evidence and uncertainty standards.
- Flexible report outline, optional research brief, and usage examples.
- Optional Codex UI metadata and normal automatic discovery.
- MIT licence and a small, script-free installable package.
- A clearly fictional sample report in the repository.

## Install

Download `market-opportunity-research-v0.1.0.zip` and `SHA256SUMS`, verify the checksum, and follow the [README](https://github.com/itstinatao/market-opportunity-research/blob/v0.1.0/README.md). The skill ZIP contains one `market-opportunity-research/` directory. GitHub's automatic source archives also contain maintainer utilities and documentation.

## Limits

Live research requires research tools provided by the host agent. Public pricing, vendor claims, and actual transactions remain distinct. The sample is fictional, and structural/security checks do not establish market-research accuracy or universal client compatibility. Outreach and paid experiments require user authorization.

Feedback is welcome on source quality, competitor coverage, commercial tradeoffs, and practical validation. Report sensitive issues through the repository's security policy.
